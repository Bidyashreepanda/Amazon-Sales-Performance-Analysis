# 🛒 Amazon Sales Performance Analysis

### 📊 Interactive Excel Dashboard | Data Analytics Project

> **Turning raw Amazon sales data into meaningful business insights using Microsoft Excel.**

This project analyzes Amazon order-level sales data to understand **sales performance, product and category trends, customer behavior, payment preferences, and order status**.

An interactive Excel dashboard was created using **PivotTables, PivotCharts, Excel formulas, and slicers** to transform raw data into an easy-to-understand business report.

---

## 📌 Project Overview

The goal of this project is to perform an end-to-end sales analysis and answer important business questions such as:

* 💰 What is the overall sales performance?
* 📦 Which products and categories generate the most sales?
* 📍 Which customer locations contribute the highest sales?
* 💳 Which payment methods are most commonly used?
* 📋 What is the distribution of completed, pending, and cancelled orders?
* 👥 Who are the highest-spending customers?
* 📈 What business insights can be derived from the data?

## 🔍 Data Analysis Process

### 1️⃣ Data Collection & Loading

The Amazon sales dataset was imported into Microsoft Excel for analysis.

### 2️⃣ Data Cleaning & Validation

The dataset was checked for:

* Missing values
* Duplicate records
* Duplicate Order IDs
* Incorrect or inconsistent values
* Sales calculation accuracy
* Data types and formatting

### 3️⃣ Data Transformation

Additional fields were created where required to support analysis, including:

* Month
* Day of Week
* Order Status categories
* Calculated sales metrics

### 4️⃣ Exploratory Data Analysis

PivotTables were created to analyze:

* Category-wise sales
* Product-wise sales
* Location-wise sales
* Payment method usage
* Order status
* Customer spending

### 5️⃣ Dashboard Development

The final dashboard combines:

* 📌 KPI Cards
* 📊 Sales charts
* 📦 Product analysis
* 🏷️ Category analysis
* 📍 Customer location analysis
* 💳 Payment method analysis
* 📋 Order status analysis
* 🎛️ Interactive slicers

# 💡 Key Business Insights

### 🏷️ Category Performance

Electronics and Home Appliances account for the majority of the sales in the analyzed dataset, making them important categories to monitor for inventory and sales performance.

### 📦 Product Performance

**Refrigerator, Laptop, and Smartphone** are among the highest-performing products based on sales.

### 📍 Customer Location

Sales performance varies across customer locations, providing an opportunity to compare high-performing and lower-performing markets.

### 💳 Payment Methods

The analysis provides visibility into customer payment preferences and helps identify the payment methods most frequently used.

### 📋 Order Status

The dashboard highlights the distribution of completed, pending, and cancelled orders, helping identify potential areas for improving order fulfillment.

### 👥 Customer Analysis

Customer-level analysis helps identify high-value customers and understand purchasing contribution.
